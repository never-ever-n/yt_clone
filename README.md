# 📺 YouTube Clone (HTML & CSS)

A simple front-end clone of the YouTube homepage built with just HTML and CSS. This project focuses on replicating the layout and user interface of YouTube, helping to improve skills in responsive design and clean UI development.

## 🚀 Features

- ✅ Responsive layout (desktop view)
- ✅ Top navigation bar with logo, search bar, and user icons
- ✅ Sidebar navigation menu
- ✅ Video thumbnail grid with titles, channels, and view counts
- ✅ Clean, organized CSS with Flexbox and Grid

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
